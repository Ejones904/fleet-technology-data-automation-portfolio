# Poor GPS Quality Event Analysis

## Problem

Recurring poor GPS-quality records could affect the reliability of location information generated by fleet technology systems.

## Approach

The query identifies records with GPS-quality values of **0 or 1**, examines records from the previous **90 days**, counts poor GPS-quality events by vehicle, associates vehicles with their operating location, and ranks vehicles by the number of poor-quality events.

## SQL Techniques

`COUNT` • `LEFT JOIN` • `IN` • `GROUP BY` • `DATEADD` • `GETDATE` • aggregation

## Operational Use

The query provided a repeatable method for identifying vehicles experiencing recurring GPS-quality issues and prioritizing them for additional investigation.

## Sanitization

Production table and column names have been replaced with generic equivalents while retaining the original troubleshooting logic and 90-day analysis window.
