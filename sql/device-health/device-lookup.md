# Device Assignment Lookup

## Problem

During troubleshooting, I needed a quick method for determining the vehicle and operating location associated with a particular device.

## Approach

I used a targeted SQL lookup based on the device identifier to retrieve its associated assignment information.

## SQL Techniques

Filtering • targeted record retrieval • relational data lookup

## Operational Use

This provided a quick way to connect a device being investigated with the corresponding fleet asset and operational assignment.

## Sanitization

Actual device identifiers have been removed.

The public query uses a fictional identifier such as:

`DEVICE-10001`

Production table names, column names, and organizational identifiers have also been replaced with generic equivalents.
