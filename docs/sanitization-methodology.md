# Sanitization Methodology

This portfolio contains sanitized reconstructions of technical work originally performed in a professional enterprise environment.

## Preserved

- Query and analytical intent
- Troubleshooting thresholds selected during the original work
- SQL constructs and visible query structure
- Python analytical methods and visible workflow

## Removed or replaced

- Company-specific database, schema, table, and field names where proprietary
- Server names, connection strings, credentials, internal URLs, and infrastructure details
- Personal workstation paths
- Driver, employee, device, vehicle, customer, and other production identifiers
- Production datasets and business records

Synthetic data is used for runnable demonstrations.

Where public-release security changes are introduced, such as environment-variable credential handling or safe execution controls, they are treated as portfolio modifications rather than represented as part of the original code.
